# 小溪 · Xiaoxi Companion

一个住在自己小房间里的 AI 陪伴：会聊天、记住相处中的事、照顾自己的生活，也能在真实 Linux 电脑上帮你做事。ESP32 小板子和网页是她的两种交互方式，共享同一个主脑和居住环境。

> 首个公开版本，持续开发中。已在 RK3399 + Waveshare ESP32-S3-Touch-AMOLED-2.16 上运行；不是所有 Linux 主机的一键整机适配包。

## 她现在能做什么

- 中文语音对话、随名字变化的本地唤醒、短句接话、音色选择。语音识别和合成依赖外部服务。
- 长期记忆、偏好归纳、任务反馈与反思；模型理解名字和初始设定，不直接把整句回答当成名字。
- 在温馨中式房间和小院活动：休息、洗漱、工作、看窗外，和小猫互动。共享场景引擎让网页和板子同步。
- 网页文字/语音输入、来源终端提醒、图片/音视频结果展示；按当前设备能力选择呈现方式。
- Linux 工作任务、浏览器 DOM/CDP 操作、验证执行结果、取消和中断恢复；可选真实桌面与 noVNC 接管。
- 板端 Wi-Fi 配网、电量/联网状态、实体按键、渐暗熄屏、触摸和重力旋转。

## 架构

```text
ESP32 屏幕 / 麦克风 / 触摸 ── HTTPS ──┐
                                    ├─ Linux 主脑 ── 模型 / ASR / TTS
PC 浏览器：房间 / 聊天 / 桌面 ─ HTTPS ┘       │
                                           ├─ NVMe 记忆、任务、媒体、缓存
                                           └─ 专用 Linux 桌面 / 浏览器 / 工作用户
```

板子负责即时交互、播放和离线唤醒；Linux 负责模型、记忆、生活决策与工作。网页不是另一只小溪。

## 给人和大模型的安装入口

先克隆，再检查；默认检查不会安装或修改系统：

```sh
git clone https://github.com/gq3171/xiaoxi-companion.git
cd xiaoxi-companion
./install.sh --check --json
```

**请让部署代理先读 [INSTALL_FOR_AGENTS.md](docs/INSTALL_FOR_AGENTS.md)**。里面有操作顺序、配置合同、验收命令、退出码、不可自动处理的情况。人类安装说明见 [INSTALL.md](docs/INSTALL.md)。

Linux 主脑安装器面向 Debian/Ubuntu、Python 3.11+、systemd、aarch64/x86_64，要求数据盘已挂载到 `/mnt/nvme`。它不分区、不格式化、不修改路由器、不自动刷板子。安装器只引导主脑和网页；**真实桌面另按 [DESKTOP.md](docs/DESKTOP.md) 配置**。

## 当前边界

首次需要 ESP32 完成身份创建并导入主脑，网页聊天才可用；暂未提供纯网页的首次创建向导。模型/API 权限、网络质量、音频环境会影响体验，本地声纹仍是实验功能，不适合作为高风险操作的身份认证。复杂网站、验证码和部分桌面应用不能保证全自动完成。

软件是 MIT；第三方字体、模型和 noVNC 保留各自许可证。仓库不含部署者的密钥、私有证书、Wi-Fi 配置、聊天数据库、主人声纹或固件私有配置。
