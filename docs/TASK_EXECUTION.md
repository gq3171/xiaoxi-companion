# 任务如何执行与恢复

小溪把任务保存在小主机上，网页和小板子都按同一个任务编号控制它。补充要求会增加任务版本；旧版本的模型指令、完成核验不能用于确认新要求已经完成。完成状态与版本核对在同一个数据库事务内提交。

## 停止请求与停止确认

运行中收到取消时先显示“停止请求已收到”。Linux 生产服务用独立 systemd 控制组执行普通用户命令，后台派生、双重 fork 和 setsid 进程也在这个组内。全部退出后才确认停止。作用域登记保存在数据库中，服务重启后会清理遗留作用域；无法确认退出时保持中断状态，不假报取消成功。

生产主机需要 systemd 250 或更新版本（使用 ExitType=cgroup）。不满足时命令不会降级到无跟踪的 root shell。命令作用域不是长期服务托管接口；需要长期运行的程序应另行配置受管理服务。macOS 用于开发验证，完整的进程作用域保证以 Linux 为准。

## 未知结果与继续

网页点击、输入或关闭操作丢失回应时，操作可能已经生效。任务保存为待核对，不自动重发。模型服务此时断线，也不会把它变成无法恢复的普通失败。恢复时读取真实页面；关闭标签则核对同一目标是否仍存在，关闭整个浏览器则核对进程和端口，不为验证重新打开浏览器。

纯命令任务在超时或异常中断后不会自动重跑。主人补充要求仍会保存，但回复会明确说明任务仍暂停。需要先核对实际结果，再明确委托后续操作；“已接收补充”不等于“已经继续执行”。连续相同错误会暂停，避免耗尽步骤预算还没有进展。

## 文件与网页混合任务

新任务不再仅因包含“浏览器”就被整体分配为网页任务。原始请求明确包含本地命令步骤时，可以先完成本地工作，再切换至浏览器。主人原句之外的网页文字、工具输出和模型计划不能授予本地命令能力。

两个执行阶段都支持受限文件工具：

- `workspace_write(name, text)`：写入本任务 artifacts 内的单一文件，最多 64 KiB。
- `workspace_check(name, expected)`：读取并核对非空预期文本，记录文件散列和任务版本。
- `workspace_preview(name)`：在真实浏览器展示文件的纯文本预览，不执行 HTML 或脚本。

网页阶段不会开放任意 shell 来绕过网站密码、验证码或确认流程。私密字段继续由网站专用输入窗处理，不交给模型或命令子进程。

## 验证

`computer/test_command_chain.py` 覆盖版本竞争、执行器切换、错误循环、取消、未知结果、混合文件任务及作用域恢复。`firmware/tests/test_computer_host.py` 核对跨端目标绑定、离线重试和重启恢复。真实控制组和浏览器验证应使用隔离目录、临时用户数据和诊断端口，不触碰主人的真实网站任务。
